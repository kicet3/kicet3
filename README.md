## 🚀 About Me

💻 LLM 기능을 실제 서비스와 연결하고 운영 문제를 해결하는 **AI 엔지니어 · 풀스택 개발자**입니다<br>
🌱 **LLM 생성·평가 워크플로우, 음성 대화, 그래프 기반 경력 분석**을 구현합니다<br>
🎯 교육용 AI 서비스, 산업용 시스템 안정화, 호텔 예약 연동을 경험하며 **데이터 연동부터 웹·데스크톱 앱 구현과 운영**까지 담당했습니다<br>
⚡ **로그·소스코드 분석과 상태 관리·결과 검증·예외 처리**를 설계하고, 팀 프로젝트 리드와 주니어 개발자 업무 배분·리뷰를 경험했습니다
